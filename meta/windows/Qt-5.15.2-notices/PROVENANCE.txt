Collection scope and method
---------------------------
All src/**/qt_attribution.json manifests from these three modules are retained.
ATTRIBUTIONS.txt repeats their component names, applicable copyright statements,
license identifiers and source locations for convenient human-readable use.
Every referenced LicenseFile is copied at its original module-relative path.
FreeType docs/FTL.TXT and GPLv2.TXT are included because docs/LICENSE.TXT
references both. Standard open-source LICENSE.* distribution texts from the
tagged modules are included as well. Text is normalized only to LF and a
terminal newline; copyright and license wording is not rewritten.

The collection includes a conservative superset (for example, non-Windows
platforms and optional plugins) to keep windeployqt plugin discovery covered.
In particular, qtimageformats TIFF/WebP notices are included whether or not
those optional image plugins are deployed. Disabled components need not be
enabled to use or redistribute this collection.

The JamesDSP portable package uses QWidget/QPainter rendering and deliberately
excludes the optional Mesa/LLVM opengl32sw.dll via windeployqt --no-opengl-sw.
ANGLE notices remain included for the normal Qt Windows GUI deployment.

This collection does not cover separate third-party binaries supplied outside
these three tagged source modules, such as an independently built Mesa/LLVM
opengl32sw.dll software rasterizer or separately supplied OpenSSL binaries.
Distributors adding those binaries must retain their matching vendor notices.
