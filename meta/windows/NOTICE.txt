This is an experimental Windows proof of concept, not a stable audio driver.
With VB-Cable installed separately, set Windows default playback to CABLE
Input and select DIFFERENT physical headphones/speakers in Settings > Devices.
Relink through the three-dot menu after routing/rate changes. Windows captures
the entire playback mix; per-app exclusion is unsupported. Matching endpoint
rates helped user testing (192000 Hz), not a universal fix. Preset loading,
sustained DSP overload and independent device clocks can still cause glitches.

Portable use and optional Windows integration
--------------------------------------------
Extract the entire ZIP to a permanent folder. Launch jamesdsp.exe directly,
or run Install.cmd to register this copy in your per-user Start Menu for
Windows Search. Registration does not change your startup-at-sign-in choice.
Windows Search may take a moment to refresh its index. No administrator
rights are required, and no source/project directory is moved.

To explicitly start in the tray at sign-in, run in PowerShell:
  .\Register-Application.ps1 -InstallDirectory . -StartWithWindows

To remove only this copy's Start Menu/startup integration, run:
  .\Unregister-Application.ps1 -InstallDirectory .

If PowerShell execution policy blocks these scripts, invoke powershell.exe
with -NoProfile -ExecutionPolicy Bypass -File and the same script/arguments,
as Install.cmd does. This changes policy only for that PowerShell process.
Unregistration never deletes application files or personal settings. If you
move the extracted folder, unregister its old location before registering
its new location. Integration pointing to a different copy is not removed.
